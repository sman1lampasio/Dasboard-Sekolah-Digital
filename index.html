Integrasi Google Spreadsheet

Hubungkan dashboard ini langsung dengan file Google Spreadsheet sekolah Anda menggunakan Google Apps Script Web App URL.

Dapatkan URL ini setelah menerapkan (deploy) script Code.gs sebagai Aplikasi Web.

Panduan Menghubungkan ke Google Sheets

Langkah 1: Buat Google Spreadsheet Baru

Buka sheets.new di browser Anda dengan akun Google sekolah. Beri nama file misalnya: Database SMAN 1 Lampasio.

Langkah 2: Buka Editor Apps Script

Di Google Spreadsheet, klik menu Ekstensi (Extensions) > Apps Script.

Langkah 3: Salin Kode Backend

Hapus isi file Code.gs bawaan Google, lalu salin seluruh isi file google-apps-script/Code.gs dari repositori ini dan tempel di editor Apps Script tersebut. Tekan Ctrl + S untuk menyimpan.

Langkah 4: Jalankan Inisialisasi Otomatis (Sekali Saja)

Di editor Apps Script, pilih fungsi setupInitialDatabase di bagian atas dan klik tombol Jalankan (Run). Berikan izin akses yang diminta oleh Google. Spreadsheet Anda otomatis akan terisi sheet dan data awal!

Langkah 5: Deploy Sebagai Aplikasi Web

Klik tombol biru Terapkan (Deploy) > Penerapan baru (New deployment).

  • Pilih jenis: Aplikasi Web (Web App)
  • Jalankan sebagai: Saya (Me)
  • Siapa yang memiliki akses: Siapa saja (Anyone) ← Wajib dipilih agar dashboard bisa mengakses data

Langkah 6: Tempel URL ke Dashboard

Salin URL Aplikasi Web yang diberikan (berakhiran /exec), lalu buka menu Pengaturan di pojok kanan atas dashboard ini dan tempelkan URL tersebut. Selesai!
